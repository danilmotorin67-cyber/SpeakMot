# SpeakMotor

SpeakMotor — локальное Windows-приложение для диктовки: голос превращается в текст.
Нажимаете горячую клавишу, говорите, текст сам вставляется в активное окно.
Всё работает офлайн: распознавание выполняет Whisper (faster-whisper) на вашем компьютере.

## Возможности

- Тёмный интерфейс на Qt: боковая навигация, карточки, анимированная кнопка записи
- Плавающая панель поверх всех окон с живой визуализацией голоса во время записи
- Глобальная горячая клавиша (по умолчанию `Ctrl+Alt+Space`), режимы «переключением» и «удержанием»
- Автовставка распознанного текста в любое окно через буфер обмена (буфер восстанавливается)
- Менеджер моделей: `tiny` … `large-v3` ставятся кнопкой, с полосой прогресса и удалением
- Автоопределение CPU/CUDA с откатом на процессор
- Выбор микрофона и языка (`ru`, `en`, автоопределение)
- Иконка в системном трее, окно настроек, история последних 50 распознаваний
- Автостоп по тишине — запись заканчивается сама, когда вы замолчали
- Отмена начатой записи по `Esc`
- Голосовые команды: «точка», «запятая», «новый абзац» превращаются в знаки,
  а предложения начинаются с заглавной буквы
- Окно предпросмотра: текст можно поправить или отклонить до вставки
- Профили под программу: свой язык, команды и способ вставки для каждого приложения
- Светлая и тёмная тема, шесть акцентных цветов
- Перевод на английский на лету: говорите по-русски, вставляется английский
- Вторая горячая клавиша для быстрой смены языка
- Поиск и экспорт истории
- Автоматическая нормализация громкости для тихих микрофонов
- Проверка обновлений в настройках
- Словарь замен: «пайтон = Python», применяется к каждому распознанному тексту
- Запасной способ ввода символами, если `Ctrl+V` перехвачен окном
- Запуск вместе с Windows
- Никаких серверов и подписок — данные не покидают компьютер

## Установка (Windows 10/11)

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Требуется Python 3.10+. При первом запуске откроется вкладка **Модели** —
выберите модель и нажмите «Установить». Файлы лягут в
`%USERPROFILE%\.speakmot\models`, дальше всё работает офлайн.

## Использование

1. Запустите приложение — оно свернётся в трей.
2. Поставьте курсор туда, где нужен текст.
3. Нажмите `Ctrl+Alt+Space`, продиктуйте, нажмите ещё раз.
4. Текст будет вставлен автоматически.

Начатую запись можно выбросить клавишей `Esc`. Если включить автостоп по тишине,
второе нажатие не потребуется.

## Профили

На вкладке **Профили** задаются правила для конкретных программ: строка
сопоставляется с именем процесса (`code.exe`) или заголовком окна (`Telegram`).
Всё, что оставлено как «как в настройках», берётся из общих настроек.
Применяется первый подошедший профиль.

## Если текст не вставляется

Некоторые окна (запущенные от администратора, игры, отдельные терминалы) не
принимают `Ctrl+V`. В настройках переключите «Способ вставки» на «Вводом
символов» — текст будет набираться посимвольно.

## Готовая сборка

Каждый push собирает приложение на GitHub Actions.
Откройте вкладку **Actions** → последний запуск **Build Windows exe** →
блок **Artifacts** → `SpeakMot-windows`. Внутри два варианта:

- `SpeakMot-setup-*.exe` — установщик, ставится без прав администратора;
- `SpeakMot-windows.zip` — портативная версия, просто распаковать и запустить.

Установка Python не нужна. Windows SmartScreen предупредит о неизвестном
издателе — сборка не подписана сертификатом.

```bat

```

Результат — `dist\SpeakMot\SpeakMot.exe`.

## Настройки

Хранятся в `%USERPROFILE%\.speakmot\config.json` и меняются из окна настроек.

## Модели

Устанавливаются на вкладке **Модели**: кнопка «Установить», прогресс в процентах,
рядом «Удалить». Переключиться на другую установленную модель — кнопка «Выбрать».

| Модель | Размер | Скорость на CPU | Качество |
|--------|--------|-----------------|----------|
| tiny | ~75 МБ | очень высокая | низкое |
| base | ~145 МБ | высокая | среднее |
| small | ~490 МБ | средняя | хорошее (рекомендуется) |
| medium | ~1.5 ГБ | низкая | высокое |
| large-v3 | ~3 ГБ | нужна видеокарта | максимальное |

## Известные ограничения

- Только Windows: горячие клавиши, звуковой сигнал и автовставка используют Windows API.
- Библиотека `keyboard` может требовать запуска от администратора, если целевое
  окно запущено с повышенными правами.
