# SpeakMot

Локальное Windows-приложение для преобразования голоса в текст — аналог SpeakFlow.
Нажимаете горячую клавишу, говорите, текст сам вставляется в активное окно.
Всё работает офлайн: распознавание выполняет Whisper (faster-whisper) на вашем компьютере.

## Возможности

- Тёмный интерфейс на Qt: боковая навигация, карточки, анимированная кнопка записи
- Плавающая панель поверх всех окон с живой визуализацией голоса во время записи
- Глобальная горячая клавиша (по умолчанию `Ctrl+Alt+Space`), режимы «переключением» и «удержанием»
- Автовставка распознанного текста в любое окно через буфер обмена (буфер восстанавливается)
- Выбор модели Whisper: `tiny` … `large-v3`, автоопределение CPU/CUDA
- Выбор микрофона и языка (`ru`, `en`, автоопределение)
- Иконка в системном трее, окно настроек, история последних 50 распознаваний
- Никаких серверов и подписок — данные не покидают компьютер

## Установка (Windows 10/11)

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Требуется Python 3.10+. При первом запуске выбранная модель Whisper скачивается
в `%USERPROFILE%\.speakmot\models` (около 500 МБ для `small`).

## Использование

1. Запустите приложение — оно свернётся в трей.
2. Поставьте курсор туда, где нужен текст.
3. Нажмите `Ctrl+Alt+Space`, продиктуйте, нажмите ещё раз.
4. Текст будет вставлен автоматически.

## Готовая сборка

Каждый push собирает `.exe` на GitHub Actions.
Откройте вкладку **Actions** → последний запуск **Build Windows exe** →
блок **Artifacts** → `SpeakMot-windows`. Распакуйте архив и запустите `SpeakMot.exe`
(установка Python не нужна).

## Сборка .exe локально

```bat
build.bat
```

Результат — `dist\SpeakMot\SpeakMot.exe`.

## Настройки

Хранятся в `%USERPROFILE%\.speakmot\config.json` и меняются из окна настроек.

## Выбор модели

| Модель | Размер | Скорость на CPU | Качество |
|--------|--------|-----------------|----------|
| tiny | ~75 МБ | очень высокая | низкое |
| base | ~145 МБ | высокая | среднее |
| small | ~490 МБ | средняя | хорошее (рекомендуется) |
| medium | ~1.5 ГБ | низкая | высокое |
| large-v3 | ~3 ГБ | нужна видеокарта | максимальное |

## Известные ограничения

- Только Windows: горячие клавиши, звуковой сигнал и автовставка используют Windows API.
- Библиотека `keyboard` может требовать запуска от администратора, если целевое
  окно запущено с повышенными правами.
